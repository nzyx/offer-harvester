01
Why

为什么需要它

海投时代，最大的浪费不是「投得少」，而是每份岗位都从头准备、却抓不住重点。JD 读不进去、面试题靠蒙、简历石沉大海。面邀收割机把这三件事交给本地大模型：你只负责把 JD 和简历丢进来，它把「分析 → 准备 → 表达」一次性做完，且所有文本都留在你自己的机器上。

02
Modes

三大产出模式

模式一

面试准备

先解析 JD（公司业务、核心技能、隐藏要求），再生成高频面试问题 + 现场要点。两步串联，不是空话套模板。

岗位分析 → 高频问题 → 现场要点
模式二

打招呼语

专业版 / 简洁版双版本，并附「别踩的坑」。Boss 直聘、猎聘、智联一键粘贴，HR 愿意点开你的简历。

专业版 · 简洁版 · 注意事项
模式三

简历优化

匹配度评分 + 经历改写（动作 / 方法 / 技术 / 成果键值化）+ 关键词植入 + 可直接复制的成稿话术。

评分卡 · 经历卡 · 成品话术

How it works

三步上手

1

粘贴岗位 JD

把招聘链接里的职责要求贴进侧边栏，自动去噪、保留关键信息。

2

支持 PDF / Word，本地解析，文件不上传，关掉复制保护也能用。

3

04
Design

核心设计

01

两步串联

先分析岗位、再生成准备，结果真正「基于分析」而非泛泛而谈，是质量的关键。

02

本地优先

仅调用你自己的 API Key，数据不离开浏览器；复制保护可一键关闭，零后台上传。

03

OpenAI 兼容

填任意 OpenAI 兼容接口地址即可，云端或本地 llama.cpp 通吃，不被厂商绑定。

04

导出即分享

结果一键导出为自包含可视化网页，无脚本、无外链，可放心转发给朋友或导师。

06
Security

安全与隐私

  • 调接口时强制 redirect:'error' + referrer:'no-referrer'，防 SSRF 跳转与 Referer 泄露。
  • 渲染层先转义所有文本再注入，AI / 用户输入不会触发 XSS。
  • 导出的 HTML 不含 <script>、不含外链，可安全分享。
  • 接口地址做协议白名单（仅 https 或本地 http），挡掉危险协议。
  • 提示：API Key 以明文存于浏览器本地存储（个人自用可接受）；共享电脑请注意退出登录。
07
Get started

快速开始

1
开启开发者模式
打开 chrome://extensions（Edge 为扩展管理页），右上角打开「开发者模式」。
2
加载已解压的扩展
点「加载已解压的扩展程序」，选择本项目文件夹。
3
填写接口
点工具栏侧边栏图标打开「面邀收割机」，在设置里填接口地址 + API Key + 模型名。
4
生成并导出
粘贴 JD / 上传简历，点对应按钮；生成后右上角可「导出 HTML」。
